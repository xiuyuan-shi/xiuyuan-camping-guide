# 修远露营指南

公开静态资料页，保留来源、地点线索及审核边界。名单包含公园、村落、区域和待核营位，不等于全部开放中的营地。维护任务目前暂停。

## 数据维护与生成

`library.json`是唯一权威库，保留完整records、sources、verifiedRows和被暂缓地点。`live-data.json`保存坐标、许可照片和历史参考路线；`policy.json`集中校验规则；`site-meta.json`保存维护状态及代码发布日期。

运行`python3 scripts/export-site.py`生成首页索引data.json、details/Cxxx.json、workbook.json和CSV，并更新资源内容版本。`python3 scripts/export-site.py --check`检查输出一致性，不写文件。普通导出发现地点减少会失败；新增已核实资料可以正常扩充，不依赖固定192条断言。

首页不加载逐行原表与全部来源图片记录。地点和来源详情按需读取，搜索文本预计算。所有旧ID、195行记录和来源保留；原文发布日期缺失时不推断年份。

现行导入兼容入口仅重新生成权威库的公开视图。`python3 scripts/import-verified.py --preview-historical 独立文件.json`会在临时副本重建历史候选；不能直接指定当前权威库或首页。历史imports和photo-supplements文件保留作审计证据，不自动回写当前库。

## 地图与路线

现有59处有来源参考点，路线从杭州武林门地铁站出发。500米以上道路匹配的历史快照保留但不提供通过校验的车程；本次有58条满足该门槛，C009西溪湿地旧路线待复核。快照、缓存、起终点和几何分别校验，不含实时路况。

主城区OSM快照范围仍为WGS84 [119.96,30.04,120.34,30.39]；26处参考点超出这一底图范围。范围外仍显示参考标记并明确告知当地底图未覆盖，不据此断言道路可通行。地图不再把视图锁死在旧范围，区域搜索会实际筛选地点。坐标与道路数据 © OpenStreetMap contributors，ODbL，下载与来源入口保留。

## 图片与天气

按2026-10-16用户请求，全部恢复优化前46处地点的180张既有图片，其中10张原有许可照片继续保留，另外170张来源配图按精确旧清单恢复并同域提供。恢复记录在photo-restorations.json，来源、署名与未知状态保留，不把恢复显示改写成已核实许可或营位。新增素材仍执行独立校验，旧内容筛选排除的图片不自动恢复。原有CC图片说明见assets/photos/ATTRIBUTION.md。历史景观不等于营位或运营状态。图片加载失败有重试入口。

Open-Meteo模型天气采用20分钟缓存，校验上海日期、模型时间、7天连续性和字段。当前模型不是现场观测；未接入官方预警。首页只请求可见且有坐标的卡片，最多两个并发请求。

正式评级仍要求具体营位、近期管理许可、独立实地反馈及20项证据。参考分按维度追溯日期和来源，缺依据或过期时待评，未知项不计零分。

## 验证与发布

`python3 scripts/check-site.py`统一执行导出一致性、来源保留、导入幂等、允许扩充与阻止覆盖、JS语法及行为回归。

`.github/workflows/validate.yml`在推送至main及PR时执行同一完整检查，任务只读取仓库内容，最长运行10分钟。本次启用已获用户批准；实际运行结果见优化与发布验收记录。

发布前完成独立审查、全部本地检查及320/390px和桌面浏览器验收，再向既有main推送；确认Pages构建成功，并匿名对比HTML、数据、脚本、路线和照片与本地内容。不要发布本机路径、认证材料、原始登录日志或无许可照片。

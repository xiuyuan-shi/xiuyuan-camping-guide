# 修远露营指南 · 杭州资料库

手机友好的公开资料页，保留地点线索、公开笔记来源和采集日期。

名单不代表已找齐杭州营地；作者说法与现行规则核验分开。原文可能需要平台登录。

内容由资料维护流程定期整理，本仓库仅包含公开页面及脱敏导出。

## 数据来源与清洗

《杭州热门露营地清单（验证版）》为主数据：实际有 195 条地点记录，每条提供费用、过夜、卡式炉、厕所、车辆到达、位置、特色、描述、三篇笔记及图片线索。已合并地点的卡片与详情优先展示验证版字段；旧资料作为补充。相反的原表记录逐行列出，不推断现行使用规则。原表笔记链接完整保留，并区分地点关联已检查与待核。

首页不展示导入审核入口或排序选择。原始核对记录保留为维护资料；[验证版逐行核对.csv](验证版逐行核对.csv) 保留原始字段和图片审核结果。错配或低质量图片不会作为营地相册展示。导入规则、计数和复现方法见 [验证版导入说明](imports/2026-09-23/README.md)。

## 真实数据服务

- Open-Meteo 当前模型天气及7日预报，20分钟缓存；非现场传感器。
- OpenStreetMap 地图与区域参考点；坐标数据 © OpenStreetMap contributors，ODbL：https://www.openstreetmap.org/copyright 。独立可下载数据层 live-data.json。
- OSRM 公共路由，武林门地铁站为起点，车程不含实时路况，24小时缓存。
- 经筛选的验证版配图、已有笔记图片、公开地点图源及 Wikimedia Commons 图片；来源链接、已知署名和授权信息随图片展示。未提供拍摄日期时不推断日期。

部分地点尚无可靠坐标或可用照片；名单不等于运营中的已核实营地。公共服务可能暂时不可用，页面明确展示失败和缺项。

## 杭州本地地图（v5）

参考青岛攻略的Leaflet本地矢量绘制方案，basemap.geojson随本站加载，包含首批点位周边的主干道路、公园、水域及区名参考点，不再加载外部地图瓦片。地图内容为OpenStreetMap区域快照，ODbL1.0，允许按许可取得和再分发，署名及公开数据下载入口均在地图中。提取范围WGS84 [119.96,30.04,120.34,30.39]，并非完整杭州市域或可实时导航地图。几何经过裁剪及简化，不能用于测绘或断言通行条件。

live-data.json另存18条OSRM路网参考路线，带查询日期；路线几何拆到 routes/ 以缩小首屏加载。路线可在外部接口不可用时继续显示；无实时路况或当前位置导航。同名公园范围参考点不是营位或入口，不能据此推断营地开放。今后扩展点位到范围外时，先补齐相应地理数据再扩大地图范围。无需高德Key，外部高德导航入口仍保留。

## 2026-09-23 手机端批注调整
首页不再展示地点总数或未知类型徽标。详情介绍合并清单描述与旧资料的补充事实，原始逐行字段放在“依据”页；概览不再展示生硬的表格摘录或内部行号提示。资料完整度允许时展示“参考星级”，按已记录的景观、活动、厕所/停车、人群适配及确切入口车程计算；页面和方法说明明确它不是已核验的质量星级。正式20项评级门槛不降低，当前没有记录符合正式评级。

以现成的本地 OSM 地图快照同名公园点为终点，增加13条武林门出发的参考路线，总计18条；每条通过OSRM获取路网里程、时长并预存。其余杭州地点缺少可确认营位坐标，不展示伪造车程或天气。`scripts/recalculate-park-routes.py` 可复现新增快照，只会接受地图内唯一同名公园和道路匹配距离不超过500米的结果；它不会把公园点当作营位入口。

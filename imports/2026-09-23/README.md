## 主数据优先级

验证版地点名称先对齐原 ID，再逐字段检查。清洗后的介绍和复查的位置片段优先展示；仅第 7、45、173 行的同地点来源足以采用费用、过夜、厕所与车辆到达主张。混合笔记聚合的布尔值不覆盖已有证据。“是（可用风暴炉）”不能转为卡式炉许可。

原表存在系统性错配：九溪介绍出现石门村、龙上村；杭州地点配成都、深圳笔记；多处复制云龙湾大桥或富阳湘溪村地址；日本雪地装备建议被分配给天石滩。未因文件名为“验证版”而将这些内容标为可信。来源匹配与内容筛选不代表实地、现行营业规则或精确拍摄位置已核实。

详情的营地介绍、出行摘要与依据区直接可见。验证版相关笔记优先，具体地点匹配度高的笔记再前置；旧资料仍作为补充。无法采用新描述时，从该地点已有证据整理介绍，不挪用其他地点内容。

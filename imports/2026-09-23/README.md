## 清洗结果

- 111 行对应 89 个已知地点，合并 22 行重复信息；84 行暂缓，包括位置泛化、名称不明、已有排除项及露营依据不足的地点。
- 保留 192 个公开地点：杭州 171、周边 20、外地 1；较上一版新增暂缓 18 个地点。原始证据在 baseline.json 保留，旧链接显示原因。
- 验证版每行各有 3 个不同链接，合计 585 个“表格行—笔记”链接，跨行去重后只有 186 个 URL。75 个关联通过地点核对，510 个关联尚未确认；三篇原表链接均保留并明确标注，不把“待核”当成可信营地证据。
- 验证版图片去重 654 个：14 张新增通过筛选，36 张沿用原审核且不改变地点绑定，595 张因内容或关联不可靠排除，9 张不可用。80 张满足候选条件的新图已通过浏览器逐张目视复核；其余不可靠关联直接拒绝，不宣称对所有图做了视觉识别。
- 89 个已合并的营地详情完整显示对应原表每行的 3 篇笔记；重复行另行展开。其余 84 行在“验证版逐行核对”页仍可查看原表三篇链接、字段与暂缓原因。

## 主数据优先级

验证版地点名称先对齐原 ID。所有行的免费/付费、过夜、卡式炉、厕所、开车直达、位置、特色、描述、三篇笔记、互动数据和九个图片槽位都保留在 `data.json` 的 `verifiedRows`，并导出到 `验证版逐行核对.csv`。已合并地点的五项使用信息形成 `primaryFacts`，列表卡片与详情优先采用；“未知”不由旧数据填成肯定结论，合并行有冲突时逐行展示。活动许可是原表主张，不等于现场现行规则。“是（可用风暴炉）”及烧烤设施不自动等同卡式炉可用。

原表存在系统性错配：九溪介绍出现石门村、龙上村；杭州地点配成都、深圳笔记；多处复制云龙湾大桥或富阳湘溪村地址；日本雪地装备建议被分配给天石滩。未因文件名为“验证版”而将这些内容标为可信。来源匹配与内容筛选不代表实地、现行营业规则或精确拍摄位置已核实。

详情先展示验证版的清洗描述和全部基础字段，旧资料摘要随后补充；原表完整描述仍可在逐行核对页展开。自由文本中的混入地址和通用提示不直接充作营地事实。验证版审核通过的图片排在旧图前，未通过的广告图、错配图和失效图不展示为营地照片。逐行核对页显示图片审核数量，完整图片 URL 和状态保留在 CSV。

## 维护与验证

- `source-rows.json`：去掉分享参数的输入快照，原 Excel 未修改。
- `decisions.json`、`field-review.json`：每行的合并、笔记关联与字段取舍。
- `held-places.json`、`image-review.json`：地点及图片的准入审核。
- `baseline.json`：上一版数据快照，用于稳定 ID 和可重现输出。
- `python3 scripts/import-verified.py`：重建公开数据、CSV 与数据版本。
- `验证版逐行核对.csv`：195 行原表字段与笔记、图片审核结果；可从网站页脚下载。
- 历史入口 `scripts/import-camps.py` 自动转到主数据导入，防止复活旧的排除项。
- `python3 scripts/test-verified-data.py`：检查 ID、关联、图片绑定、原图分享参数清理、CSV 及两种导入入口的幂等性。

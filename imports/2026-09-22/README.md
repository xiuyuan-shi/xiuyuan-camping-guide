## 清洗规则与发现

- 对名称、地址和原笔记 ID 进行比对。宣王桥、青年林、南湖公园等别名合并到原有 ID；保留原有备注和证据。地理区域和区域内具体经营营地不因相似名称而自动合并。
- 表格中 59 行因缺少可定位名称、合集/路线描述、乱码或疑似同名异地等原因暂缓入库。每一行都有处理结果，见 `row-review.csv`。
- 同一笔记对应多个地点时，暂不把其费用、设施、活动描述分配给每个地点，共暂缓采用 310 组字段。原值保留在来源数据中，后续可逐条复核。
- 孤山公园的同一篇来源在表格不同记录中出现“可用卡式炉”与“禁止明火”的冲突，本次未将该字段导入为肯定许可，并展示冲突说明。
- “有风营地”一条记录指向双浦镇并标注免费，另有来源描述 78 元动物体验。前者身份不明，保留待核；后者合并到原有地点，不用未核实地址覆盖旧库。
- 修复可由现有名称及来源明确对应的“西��源谷”匹配，但保留原表文本用于追溯；其余乱码不猜测修复。
- 51 行总互动量与点赞、收藏、评论之和不符。同时保留原总数和重算值，不把互动量用作营地质量评分。原表没有采样日期，不用导入日期冒充采样日期。
- 图片单元格拆分后得到 963 个去重 URL（含第二版补充）。仅保留为来源线索，未确认地点归属、拍摄日期及转载许可的图片不进入实景相册。
- 小红书笔记链接按笔记 ID 去重，清除分享查询参数。已有来源不因表格重复出现而增加来源数量。
- 新资料均标注为“表格摘录（未复核原文）”。缺失值保持未知，原始 Excel 未修改。

## 应用改动
